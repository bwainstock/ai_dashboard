# Ticket 6: Lunch on the Daily Brief

> [!NOTE]
> Historical ticket specification. See the
> [production device-client contract](../device-client-contract.md) for current
> behavior.

This display feature is deferred. The active Daily Brief contains only dated
weather forecasts and calendar entries, and scheduled generation does not fetch
MealViewer.

The historical lunch adapter and tests remain available for a future product
decision, but lunch data must not affect active generation publication or the
device view cycle.
